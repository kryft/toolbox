# MCP specification snapshot

Target protocol version: 2025-11-25.

This directory contains a focused snapshot of the official Model Context
Protocol specification for implementing a minimal stdio tools server.

Included:

- `overview.md`: base JSON-RPC protocol rules
- `lifecycle.md`: initialization and shutdown
- `transports.md`: stdio transport
- `tools.md`: tools/list and tools/call
- `schema.ts`: authoritative protocol type definitions

The prose files were downloaded using the official site's “MD for LLMs”
option. `schema.ts` was taken from the official repository's `2025-11-25`
release tag.

The original files are authoritative. Any generated summary is only a
navigation aid.
